Сюда кладите скриншоты отзывов (jpg или png).

Дальше откройте assets/js/data.js и добавьте отзыв в список reviews:

  { name: "Айгерим", city: "Алматы", date: "август 2026",
    text: "текст отзыва как есть",
    image: "assets/reviews/имя-файла.jpg",
    featured: true }

image  — не обязателен, можно только текст.
text   — не обязателен, можно только скриншот.
featured: true — крупная карточка (достаточно одной).

Пока список reviews пустой, секция «Отзывы» на сайте не показывается.
Отзывы не придумываем — публикуем только реальные.
