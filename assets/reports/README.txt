Сюда кладите фотоотчёты и фото реальных заказов (jpg или png).

Дальше откройте assets/js/data.js и добавьте кадры в список reports:

  { src: "assets/reports/имя-файла.jpg", caption: "Проверка перед отправкой", wide: true }

wide: true — крупный кадр во всю ширину (достаточно одного).

Первые четыре кадра попадают в секцию «Вы видите свой заказ до отправки»,
остальные — в секцию «Реальные заказы». Пока список пуст, галереи скрыты.

Хороший размер файла: длинная сторона 1600–2000 px, вес до ~400 КБ.
Логотип Makka Buyer на фото не убираем.
